What this screen wires to (backend already shipped in Slices 4, 5)

  • · Invite → generateStaffInvite returns an 8-char code (shown XXXX-XXXX) + 7-day expiry; "Share link" uses link.getstitchpad.com/join?code=.
  • · Pending request = a membership doc in status: pending; Approve → approveStaffMember, Decline → revokeStaffMember.
  • · Active member overflow → Revoke access → revokeStaffMember (instant, per the rules' doc-status check).
  • · Seats = staffSeatCap entitlement (default 2). Invite is disabled at the cap. Monetization gate (Pro/Atelier) is open now under the launch-free grant.
  • · Owner reaches this from the Settings → Team row (hidden for staff in Slice 6d).
