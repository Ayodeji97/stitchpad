## 1. Bug: staff sessions spin on denied Firestore listeners (do first, small)

Found on the emulator rig: logged in as staff, these listeners are denied by rules
(by design) and the app re-subscribes ~2×/second forever, log always "attempt 1":
- `collectionGroup('private') where ownerId == …` (money/contact) in the customer and order repositories
- `SyncStatusObserver` on `users/{ownerUid}`

The UI falls back correctly, so users don't see it — but it burns reads and battery.
Fix: don't open listeners staff can never read (gate on role/membership), and make the
retry path back off and stop on `PERMISSION_DENIED`. Add a test that a permission-denied
listener is not retried. Reproduce with `docs/staff/slice8-emulator-smoke-runbook.md`
(note: port 8080 may be taken locally — run Firestore emulator on 8085 by editing
`firebase.emulator.json` + `EmulatorConfig.kt` locally, never commit).
